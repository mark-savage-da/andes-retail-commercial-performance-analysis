# Andes Retail Commercial Performance Analysis

Power BI dashboard project focused on commercial performance, revenue behavior, profitability, customer segments, product categories, regional analysis, and business interpretation.

## Project Status

This repository contains the approved project notebook, the Power BI dashboard file, and the dataset used for the analysis.

The project is part of a professional data analytics portfolio. Future updates will include dashboard screenshots, improved visual presentation, stronger business storytelling, cleaner documentation, and a premium portfolio version.

## Project Overview

This project analyzes the commercial performance of Andes Retail Group during 2024–2025.

The dashboard was built in Power BI to evaluate business performance across customer segments, product categories, countries, and regions.

The analysis focuses on revenue evolution, profitability, commercial patterns, geographic performance, and potential improvement opportunities.

## Business Relevance

This project is especially relevant for Business Intelligence and Marketing Data Analytics because it connects transactional sales data with executive decision-making.

The goal is not only to build a dashboard, but to translate business data into insights that can support commercial strategy, performance monitoring, and opportunity detection.

## Current Files

- `andes-retail-commercial-performance-project-notebook.ipynb`: approved project notebook with documentation, SCQA narrative, evaluator feedback, and business interpretation
- `andes-retail-commercial-performance-powerbi-dashboard.pbix`: Power BI dashboard file
- `andes-retail-group-2024-2025-dataset.xlsx`: transactional dataset used for the dashboard
