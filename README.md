# Andes Retail Commercial Performance Analysis

Power BI dashboard project focused on commercial performance, revenue behavior, profitability, customer segments, product categories, and regional business analysis.

## Project Status

This is a temporary portfolio version.

The current repository contains the approved project notebook, the Power BI dashboard file, and the dataset used for the analysis. This version is uploaded as a working base and will be progressively improved.

Future updates will include dashboard screenshots, visual polish, stronger business storytelling, cleaner documentation, English dashboard presentation, and a premium portfolio version.

## Project Overview

This project analyzes the commercial performance of Andes Retail Group during 2024–2025.

The dashboard was built in Power BI to help understand revenue evolution, profitability, customer segment performance, product category contribution, and geographic differences across Peru, Chile, and Colombia.

## Business Relevance

This project is relevant for Business Intelligence, commercial analytics, and marketing data analytics because it connects transactional sales data with executive decision-making.

The goal is not only to present metrics, but to organize them into a dashboard that helps identify business patterns, risks, and opportunities.
